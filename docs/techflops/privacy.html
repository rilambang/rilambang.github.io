Privacy Policy

TechFlops Publisher, last updated 19 November 2026.

TechFlops Publisher is a private command-line tool used only by Muhammad Ilham Rilambang, owner of the TechFlops YouTube channel, to upload his own videos to his own YouTube channel and Instagram account. It is not offered to, or used by, anyone else.

YouTube API Services

TechFlops Publisher uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

The tool requests only the youtube.upload permission. It uses it to upload the video files, titles, descriptions, tags and thumbnails the owner chooses, to the owner's own channel. It does not read, collect, analyse or store any other YouTube data, and it never accesses another user's account.

What data is stored, and where

The only data stored is the OAuth token for the owner's own Google account, kept in a local file on the owner's computer. Nothing is sent to any server other than Google's (and Meta's, for Instagram uploads). Nothing is shared with or sold to third parties.

Retention and deletion

The token is kept only while the tool is in use and can be deleted at any time by removing the local token file. Access can also be revoked at any time on the Google security settings page, after which the tool holds no data.

Cookies and tracking

The tool has no website component and uses no cookies, analytics or tracking.
