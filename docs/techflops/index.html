TechFlops Publisher

The private upload tool behind the TechFlops channel on YouTube.

TechFlops is my YouTube and Instagram channel of animated stories about technology: where it came from, and why some of it flopped.

TechFlops Publisher is a small command-line script I run on my own computer to upload my finished videos to my own channel. It uses YouTube API Services (only the youtube.upload permission) and the Instagram Graph API. It is not offered to anyone else.
